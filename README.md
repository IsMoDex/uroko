# Uroko

Uroko — платформа для создания интерактивных уроков и презентаций с помощью ИИ. Она позволяет загружать учебные материалы, создавать слайды и задания, а затем проходить урок с ИИ-учителем.

## Возможности

- Генерация уроков на основе темы или загруженных материалов.
- Интерактивный класс с вопросами к ИИ-учителю.
- Экспорт урока в PPTX или автономный HTML.
- Подключение моделей через OpenAI-совместимые API и других поддерживаемых провайдеров.
- Браузерная или серверная озвучка при настройке соответствующего провайдера.

## Запуск для разработки

Необходимы Node.js 22.19+, pnpm 10 и PostgreSQL. Скопируйте `.env.example` в `.env.local`, задайте `DATABASE_URL`, затем скопируйте `openmaic.example.yml` в `openmaic.yml` и настройте модель и ключ согласно [документации по конфигурации](packages/docs/content/docs/configuration.ru.mdx). Ключи не добавляйте в репозиторий.

```bash
git clone https://github.com/IsMoDex/uroko.git
cd uroko
pnpm install
pnpm dev
```

Откройте <http://localhost:3000>. Для параллельной генерации сцен можно установить `PARALLEL_SCENE_CONCURRENCY=2` в окружении сервера. Озвучка, генерация изображений и поиск требуют соответствующей настройки провайдеров.
